# Timeline Core v2 Feature Matrix

Status vocabulary: `IMPLEMENTED` means the stated scope compiled and passed reproducible tests; `PARTIAL` means a tested host implementation exists but app/platform integration or broader acceptance evidence is incomplete; `UNVERIFIED` means source is present but its required build/runtime/device check could not run; `NOT IMPLEMENTED` means there is no implementation claim; `BLOCKED` means a required tool or environment is absent.

| Feature / claim | Status | Evidence / gap |
|---|---|---|
| Integer Flicks timebase, checked arithmetic, rational frame-rate conversion | PARTIAL | C++23 core direct runner passed on this source revision. Android NDK/libc++ integration is unverified. Kotlin boundary conversions are exact integer/rational code but its tests/build are unverified. |
| Canonical edit-core project validation, deterministic FNV-1a hash, schema-v1 codec | PARTIAL | Named host tests cover validation, stable errors, deterministic hash, golden bytes, round-trip, malformed input, and seeded mutation. The codec intentionally excludes app media/color/transform metadata. |
| Trim preview/commit use the same pure result | PARTIAL | `computeTrim` is the sole native trim calculation; both Compose canvases request native preview results and commit the same command batch. Native regression is tested; Android wiring is source-present but uncompiled. |
| Move / insert / delete / split / slip / slide / roll / ripple validate-then-commit | PARTIAL | Host regressions cover edit rules, locks, atomic rejection, F1 reversed-trim deltas, F2 rejected moves, ripple union, ordering-independent slide adjacency, and unsupported ripple flags. App JNI/Android behavior is unverified. |
| Bounded undo/redo delta journal and conflict rejection | PARTIAL | Native history stores per-clip before/after deltas and validates hashes before/after restoration; `TL_E_HISTORY_CONFLICT` is stable code 22. Host tests cover structural round-trips, ordering, external mutation, bounded history, 10,000 randomized multi-track operations, and 10,000 single-clip undo/redo cycles. |
| Native snap calculation / config | PARTIAL | C++ snap is checked against an independent deterministic oracle for 10,000 inputs. The Kotlin adapter now sends grid interval in frames so conversion to Flicks occurs in C++; no Kotlin snap mirror is maintained. JNI and Android execution remain unverified. |
| v2 JNI registration, Kotlin transport, and error mapping | UNVERIFIED | `timeline_core_v2_jni.cpp` uses explicit `RegisterNatives`; `NativeTimelineCoreV2.kt` and `TimelineCoreV2Adapter.kt` provide the source boundary. No Android NDK/JDK is present for ABI/link/Gradle verification. |
| ViewModel, Compose ghost/commit, undo/redo, Ripple/Roll/Blade routing | UNVERIFIED | Source inspection shows normal and advanced canvases preview through `TimelineCoreV2Adapter`; `TimelineViewModel` translates all edit command types to native commits; the specialized tool controllers dispatch through that same mapping. Android tests/runtime are unavailable. |
| Native-unavailable behavior (no divergent Kotlin edit/snap fallback) | UNVERIFIED | Adapter and gesture source fail closed; named Kotlin test sources exist but could not be compiled or run. |
| Duplicate edit/query/validation paths | PARTIAL | `CoreEditEngine`, `TimelineValidator`, `TimelineQuery`, and the unused legacy `timeline.model` clip/track/timeline/timecode types are compile-guarded with `DeprecationLevel.ERROR`; no current app call-sites were found for those guarded APIs. `CoreTimelineEngine` keeps metadata operations and delegates clip insertion/moves to v2. Android compilation has not verified the guards. |
| User-facing linked-group membership creation/reassignment | NOT IMPLEMENTED | No app action currently creates or changes `TimelineClip.metadata["linkedGroupId"]`; the lock menu supports groups only when a project already contains persistent IDs. |
| Group IDs / group-lock mapping and native lock controls | PARTIAL | `linkedGroupId` persists in clip metadata; `TimelineClip.isGroupLocked` defaults false for legacy records. The adapter maps IDs/flags and validates round-trips. C++ rejects edits to any locked group member; native `SetGroupLock` changes all group members atomically and participates in undo/redo (host-tested). Both canvases expose a long-press lock action and fail closed when native is unavailable. The menu recognizes only already-persisted group IDs; Kotlin payload/UI/serialization tests are source-only and Android UI/JNI/build validation remains unverified. |
| Compose visible-child culling for large projects | UNVERIFIED | Both canvases use `TimelineVirtualization.visibleClips`; `TimelineVirtualizationTest` covers 500 clips / 20 tracks. Android test/build could not run; track headers/backgrounds still iterate tracks. |
| 500+ clips / 20+ tracks: 60 fps, <1% jank, scrub latency, memory/thermal budgets | UNVERIFIED | No Android SDK/NDK, emulator, Perfetto/Macrobenchmark runner, or physical device is available. Host C++ benchmarks are not Compose/device evidence. See [`PERF.md`](PERF.md). |
| Rational frame/sample and Media3 output-frame conversion | UNVERIFIED | `TimelineFrameMath` includes exact rational/floor/ceiling helpers; `Media3TransformerBackend` now uses ceiling frame counts and rejects a zero-frame validated plan. Kotlin tests and backend compile/run are blocked. |
| Android Gradle tests and requested `:app:assembleDebug` | BLOCKED | No `java`, `javac`, Android SDK, or Android NDK is available in this execution environment. See [`PLAN.md`](PLAN.md) for phase gates. |
| Android launcher/Color instrumentation smoke and mobile gate runner | SOURCE ONLY | `ExampleInstrumentedTest` launches the real app and opens the Color workspace; `tools/run_color_grading_mobile.sh` preflights JDK 17+, SDK, pinned NDK, and an authorized device, then runs focused/full JVM tests, `:app:assembleDebug`, `:app:connectedDebugAndroidTest`, install, and launcher start. Neither the test nor the runner has executed an Android toolchain here; the blocked preflight is recorded in `docs/evidence/COLOR_GRADING_MOBILE_20261120T062725Z.log` (timestamp is an artifact ID). |
| Full preview/export frame parity, render graph/cache keys, OTIO, audio clock/graph | SOURCE / UNVERIFIED | Export now evaluates each clip through the shared `GradeEvaluationEngine.evaluateClipGrade` composer and renders it with the same `VideoAdjustmentEffect` shader as preview; validation fail-closes on animated grades, blend modes, and Color Match, and export pre-loads referenced LUT data. No Timeline Core v2 renderer/render-graph contract is integrated and no device MP4 comparison has run. The deleted placeholder `ExportRenderPipeline` was not a verified exporter. |
| Zero-copy hardware-buffer ownership / Android sanitizers / 16 KB ELF alignment | NOT IMPLEMENTED / UNVERIFIED | No v2 hardware-buffer renderer or Android binary was built here. |
| Legacy `NATIVE_CPP` preview option | REMOVED | Its Kotlin engine advertised capabilities over no-op JNI stubs; the option, bridge, native stub, and CMake target were removed rather than claim support. |
